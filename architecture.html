Architecture

Cascaded real-time voice pipeline: Twilio Media Streams bridge PSTN audio into FastAPI, then Deepgram STT → LLM tools → Cartesia/ElevenLabs TTS, with a Next.js dashboard for control and observability.

Design notes

Cascaded, not black-box realtime. Each stage is a swappable adapter so latency and failures stay visible (STT ms · LLM first sentence · TTS first byte · e2e).

Barge-in. Deepgram interim transcripts cancel the in-flight speak task and send Twilio clear so the agent stops mid-sentence when the caller talks.

Tools → dashboard. Promise-to-pay, lead qualify, and escalate write structured capture_json shown on the call detail page.

Demo-scale concurrency. Multiple calls can run as isolated async pipelines on one process. Production scale would add Postgres, dial queues, and horizontal media workers.
